# Project Instructions

## Tech Stack

* Next.js with App Router
* TypeScript
* API Routes
* Neon PostgreSQL
* Tailwind CSS

## Development Rules

* Use TypeScript throughout the project.
* Do not use `any` unless absolutely necessary.
* Follow the existing Next.js App Router project structure.
* Keep the implementation simple and appropriate for a small web application.
* Avoid unnecessary dependencies.
* Reuse existing components and utilities when appropriate.
* Keep API responses consistent and easy to understand.
* Validate user input on the server side.
* Handle errors appropriately.
* Do not expose environment variables or secrets to the client.

## Database

* Use Neon PostgreSQL for persistent data.
* Store the database connection string in environment variables.
* Never hard-code database credentials.
* Check the existing database structure before making changes.

## Implementation Workflow

Before implementing a feature:

1. Inspect the existing project structure.
2. Understand the requirements.
3. Consider the data model and API design.
4. Implement the smallest complete solution.
5. Check for TypeScript or runtime errors.
6. Review the implementation before finishing.

## UI

* Keep the UI simple and clean.
* Make the application usable on common desktop and mobile screen sizes.
* Use Tailwind CSS when styling is needed.

## Important

* Do not add features that are not required by the task.
* Prefer simple, maintainable solutions over unnecessary complexity.
* When requirements are unclear, inspect the existing code and follow the task requirements rather than making assumptions.
